Binge and Bliss:
I have thoroughly analyzed the Binge N Bliss codebase. Here is a comprehensive overview of the architecture, key components, data flow, and features.

1. Overview & Architecture
Binge N Bliss is a full-stack web application designed for celebrating venue bookings and managing a monthly Lucky Draw system.

Architecture: Separated Frontend (/frontend) and Backend (/backend).
Frontend: Built with React 19, Vite 8, and Vanilla CSS (App.css), using native fetch for API calls.
Backend: Built with Express 5 (Node.js ES modules), using JSON files (store.json) and Excel sheets (lucky-draw-customers.xlsx) for lightweight data persistence.

Key Features & UI Components:
Dynamic Celebration Ticker: Rotates event types (Birthday parties, Anniversary days, Private theatre, etc.) in the hero section.
Booking & Coupon System: Computes 10% discount on orders when member coupon (BLISS10) is validated.
Real-Time Draw Status Polling: LuckyDraw.jsx polls /api/lucky-draw/status every 1 second to automatically animate and present winner announcements when triggered by admin.
API Service Layer:

3. Backend Structure (/backend)
Routes & Controllers
Routes (src/routes/luckyDrawRoutes.js):
POST /api/auth/login: Authenticates or registers customers using a 10-digit phone number or email.
POST /api/coupons/validate: Validates member coupons and returns calculated discounts.
POST /api/orders: Receives booking requests and stores them in orders.
POST /api/lucky-draw & GET /api/lucky-draw/status: Customer lucky draw entries & status checks.
POST /api/admin/login: Admin authentication verifying ADMIN_EMAIL and ADMIN_PASSWORD.
POST /api/admin/lucky-draw/spin: Selects a random winner, records the spin state, and attempts WhatsApp notification.
GET/PUT/DELETE /api/admin/customers: CRUD endpoints for Excel data management.
Data Storage & Integrations
JSON Data Persistence (

db.js
): Stores users, orders, and luckyDrawSettings inside backend/data/store.json.
Excel Workbook Operations (

luckyDrawExcel.js
): Uses xlsx (SheetJS) to manage backend/data/lucky-draw-customers.xlsx. Includes conflict handling for EBUSY/EPERM errors when Excel is opened locally.
WhatsApp Cloud API Integration (

whatsapp.js
):
Automatically formats 10-digit Indian numbers with 91 country code.
Attempts to send a WhatsApp notification via Facebook Graph API (v21.0).
Fallback: Generates a prefilled wa.me link so the admin can open WhatsApp directly and send the message manually.
4. Running the Project Locally
Backend:
bash
cd backend
npm run dev    # runs `node --watch server.js` on port 4000
Frontend:
bash
cd frontend
npm run dev    # runs Vite dev server on port 5173
